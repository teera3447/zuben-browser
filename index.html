GOOD TO KNOW

คำถามที่พบบ่อย

Zuben ใช้งานบนระบบปฏิบัติการใดได้บ้าง?＋

แพ็กเกจปัจจุบันสำหรับ Windows 10 และ Windows 11 แบบ 64-bit

ต้องติดตั้ง uBOLite เองหรือไม่?＋

ไม่ต้อง รุ่น Windows ที่ดาวน์โหลดมาจะมี uBOLite และตั้งค่าให้โหลดพร้อมโปรแกรม

ใช้ส่วนขยาย Chrome ทุกตัวได้หรือไม่?＋

รุ่นนี้รวม uBOLite ที่ทำงานกับ Chromium รุ่นปัจจุบัน ส่วนขยายจาก Chrome Web Store อาจใช้งานไม่ได้ครบทุกตัวใน CEF

มีการซิงก์บัญชี Chrome หรือไม่?＋

ยังไม่มีการซิงก์บัญชี Google ระหว่างอุปกรณ์ โปรไฟล์และเซสชันจะเก็บไว้ในเครื่องนี้
